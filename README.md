# Política de Privacidade - Backup Pessoal Rclone

Esta Política de Privacidade descreve como as informações pessoais são coletadas, usadas e compartilhadas ao utilizar o aplicativo/script de integração pessoal com o Google Drive ("Aplicativo").

## 1. Coleta de Dados
Este Aplicativo é uma ferramenta de uso estritamente pessoal/interno para automação de backups. Não coletamos, armazenamos ou transmitimos nenhum dado pessoal, credencial ou arquivo do usuário para servidores externos ou terceiros.

## 2. Uso das Informações do Google Drive
O acesso concedido às APIs do Google Cloud/Google Drive é utilizado exclusivamente para:
- Ler, gravar e sincronizar arquivos locais com a conta do Google Drive configurada.
- Executar rotinas automatizadas de backup e manutenção de arquivos.

## 3. Armazenamento de Tokens e Credenciais
As credenciais de acesso (Client ID, Client Secret e Refresh Tokens) são armazenadas localmente no ambiente do usuário e nunca são compartilhadas com terceiros.

## 4. Compartilhamento de Dados
Nenhum dado do usuário ou arquivo sincronizado é vendido, compartilhado ou transferido para terceiros sob nenhuma circunstância.

## 5. Contato
Caso tenha dúvidas sobre este aplicativo pessoal, entre em contato pelo e-mail do proprietário da conta no Google Cloud Console.
